# NS Delay Predictor
Predicts whether a Dutch train departure will be disrupted (≥5 min late or cancelled),
built as an end-to-end MLOps project.

**Data:** [Rijden de Treinen](https://www.rijdendetreinen.nl/en/open-data) train archive (CC BY)
**Status:** 🚧 Week 1 — data exploration

## Findings so far
- ~190k services / ~2M stops per month
- 11.6% of departures disrupted (target)
